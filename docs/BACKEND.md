# Краткие сведения о серверной части

## Стек
- TypeScript.
- Express.
- Библиотека ws
- PostgresSQL (библиотека pg).

## Файловая структура
- В `src/app/` точка входа в приложение: глобальные миддлвейры, подключение роутеров, настройка ws-сервера.
- В `src/features/` обработчики маршрутов по сущностям.
- В `src/shared/` вынесен код, который используется в нескольких частях приложения.

## Парадигма
- Преимущественно ФП.

## Слои (по порядку выполнения)
- **Роутеры** (*.routes.ts) экспортируют роутер, который объединяет http-маршруты по сущностям.
- **Сокет-роутеры** (*.sockets.ts) экспортирует объект с ключом-событием, значением-сокет-контроллером.
- **Контроллеры** (*.controller.ts) точка входа в http. Получают данные и передают их в сервисы. 
- **Сокет-контроллеры** (*.socket.ts) точка входа в ws. Получают данные и передают их в сервисы. 
- **Стратегия (редко)** (*.strategy.ts) получает данные из контроллера, передает их в нужный сервис и возвращает ответ.
- **Сервисы** (*.service.ts) работают с полученными данными.
- **Репозитории** (*.repository.ts) получают данные из БД и вызываются сервисами.

## Обработка ошибок
- В HTTP:
  1) Ошибки выбрасываются сервисом. 
  2) Это может быть либо ошибка с сообщением, которое показывается на клиенте (класс `ClientError`), либо стандартный `Error` — не отправляемая клиенту ошибка 500.
  3) Все ошибки попадают в контроллер, который проталкивает их в `errorHandler`. 
- В WS аналогично, но ошибки ловятся в `handleError` в обработчике wss.

## Парсинг и маппинг
- Контроллеры парсят запрос с клиента с помощью универсальных `parseRequest`, `parseWSMessage` для HTTP, WS соответственно.
- Универсальные мапперы располагаются в `shared/mappers`.

## Типизация
- **Domain-типы** (`shared/types/domain/`) получают и возвращают сервисы. 
- **DB-типы** (`shared/types/db/`) возвращают репозитории. Отличаются от доменных только snake_case-ом.
- **DTO-типы** (`@forum/shared`) маппятся из доменных в контроллерах при отправке на фронтенд.

## Переменные окружения
- Доступны в `.env` в корне проекта.
- `.env.example` — шаблон для заполнения.
