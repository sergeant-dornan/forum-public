# Краткие сведения о серверной части

## Стек
- TypeScript.
- Express.
- PostgresSQL (node-pg).

## Файловая структура
- В `src/http/` располагается RESTful API. Названия подпапок соответствуют названиям сущностей.
- В `src/ws/` располагается работа с WebSocket.
- В `src/shared/**/*` вынесен код, который используется в нескольких частях приложения.

## Парадигма
- Работа с HTTP написана на ФП.
- Работа с WS написана на ООП.

## Разделение ответственности в HTTP
- **Роутеры** (*.routes.ts) экспортируют роутер, который объединяет маршруты по сущностям.
- **Контроллеры** (*.controller.ts) получают данные и передают их в сервисы. 
- **Сервисы** (*.service.ts) работают с полученными данными.
- **Репозитории** (*.repository.ts) получают данные из БД и вызываются сервисами.

## Обработка ошибок
Ошибки выбрасываются сервисом. Это может быть либо ошибка с сообщением, которое показывается на клиенте (класс `ClientError` из `src/shared/utils/`), либо стандартный `Error` — не отправляемая клиенту ошибка 500. Все эти ошибки попадают в контроллер, который проталкивает их в `errorHandler` из `src/shared/middlewares/`.

## Типизация
- Источник всех глобальных типов приложения — домен. Глобальные типы только бэкенда расположены в `shared/types`.
- В репозиториях используются и возвращаются db-типы, сервисы парсят их утилитой.

## Переменные окружения
- Доступны в `.env` в корне проекта.
- `.env.example` — шаблон для заполнения.
