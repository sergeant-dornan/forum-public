# Техническая информация
- Монолит.
- Монорепозиторий:
```
  shared/
  frontend/
  backend/
```
- npm.
- Папка `shared` — локальный npm-пакет для общих типов.
- Сессии для аутентификации (Хранятся в БД и куках).

## Стек
- TypeScript.
- Next.
- Express.
- WebSocket.
- PostgresSQL.
- Zod для валидации api-схем.
